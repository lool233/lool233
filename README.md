### 一些工程习惯

- 写业务先想**失败路径**：LLM 超时、密钥缺失、网络不可用时，系统还能不能跑
- 能用机制约束的，不靠提示词祈祷（白名单模板 > 让模型直接输出 SQL）
- 改完代码先跑测试，再谈优化
